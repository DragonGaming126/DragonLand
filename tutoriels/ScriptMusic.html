Script - Lancer une musique dans Roblox Studio

Regardez la vidéo explicative sur YouTube :

Vidéo YouTube : Script - Lancer Une Musique [- ROBLOX STUDIO -]

Tutoriel écrit

Ce tutoriel vous guide pour ajouter et gérer une musique dans Roblox Studio à l'aide d'un script Lua. Suivez ces étapes :

  1. Obtenir une musique : Rendez-vous sur la Roblox Creator Marketplace ou utilisez un ID de musique de la bibliothèque Roblox (ex. rbxassetid://1838457617).
  2. Ajouter un objet Sound : Insérez un objet Sound dans le Workspace ou ReplicatedStorage, et définissez la propriété SoundId.
  3. Créer un script Lua : Ajoutez un Script dans ServerScriptService pour contrôler la musique.
  4. Tester le jeu : Lancez le jeu et vérifiez que la musique joue correctement.

Exemple de programme Lua

--- Script pour gérer une musique dans Roblox Studio
--- ---------------------------------------------

--- Initialisation de l'objet Sound
local sound = Instance.new("Sound")
sound.SoundId = "rbxassetid://1838457617" -- Remplacez par l'ID de votre musique
sound.Volume = 0.5                         -- Volume (0 à 1)
sound.Looped = true                        -- Boucler la musique
sound.Parent = game.Workspace              -- Placer le son dans le Workspace

--- Fonctions de contrôle de la musique
--- -----------------------------------

--- Jouer la musique si elle n'est pas déjà en cours
local function playMusic()
    if not sound.IsPlaying then
        sound:Play()
        print("Musique en cours !")
    end
end

--- Arrêter la musique si elle est en cours
local function stopMusic()
    if sound.IsPlaying then
        sound:Stop()
        print("Musique arrêtée.")
    end
end

--- Exécution initiale
--- -----------------

--- Lancer la musique au démarrage
playMusic()

--- Arrêter la musique après 10 secondes (facultatif)
wait(10)
stopMusic()
